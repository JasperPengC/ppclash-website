# 快速上手

从安装到稳定出口，只需四步。Android 的安装要求与操作入口见 [Android 使用指南](/guide/android)。

## 1. 导入订阅或本地配置

打开 PP Clash，进入订阅管理页：

- **订阅链接**：粘贴机场或自建服务的订阅 URL；
- **本地文件**：选择本地 Clash 配置文件导入。

导入时会校验配置，失败会保留可用数据并说明原因。Android 可从底部“订阅”进入，选择本地文件时使用系统文件选择器。

::: danger 没有订阅？
PP Clash 不提供代理节点或订阅服务，请自行准备订阅链接或配置文件。
:::

::: tip macOS 首次打开
macOS 首次打开可能需要先在“系统设置 → 隐私与安全性”中允许打开，详见[下载与安装](/guide/install#macos)。
:::

## 2. 选择节点

进入代理节点页：

- 分组名称与结构由你的订阅决定，按实际名称浏览；
- 搜索节点，点击闪电图标测试延迟；
- 选择节点后可以固定。稳定出口优先于最低延迟——测速不会自动切换节点。

所选节点会在下次打开应用时恢复。Android 概览页也可以点击当前节点名称进入节点页，或点击延迟圆环测速。

## 3. 开启接管

### 桌面端

回到概览页，按需开启：

- **系统代理**：接管系统代理流量，显示真实监听端口；不接管 UDP；
- **TUN**：按实际网卡与协议栈状态接管全部流量；需要 WebRTC 等 UDP 流量走代理时开启。

两种接管各自独立开关；TUN 开启时应用会阻止再开启系统代理，需先关闭 TUN。开启任一接管会自动启动 mihomo 内核；关闭最后一个接管时内核停止。

### Android

回到“概览”，点击连接按钮并允许系统 VPN 请求。确认状态显示“已连接”；再次点击即可断开。规则、全局、直连模式在概览页顶部切换。

## 4. 确认状态

桌面概览页首屏集中显示：

- 当前节点与延迟圆环（点击圆环可重新测速）；
- 上传与下载速率及最近峰值；
- 服务连通结果；
- 当前订阅的用量与到期信息。

Android 概览页显示当前节点、延迟、运行时间与实时上传、下载速率，用量和到期信息在“订阅”查看。

## 日常使用

- 托盘/菜单栏快捷面板（macOS 菜单栏 / Windows 托盘）：快速切换订阅、节点和出站模式，不必回到主窗口；
- Android 底部导航可进入节点、订阅、连接和更多工具；在“更多”查看流量统计、分流规则、DNS 和日志；
- 配置和订阅变更都可解释、可回退：失败时保留可用数据，成功提示对应实际完成的阶段。
