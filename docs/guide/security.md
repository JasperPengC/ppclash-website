# 安全防护

## 默认开启的防护

应用生成的配置默认启用：

- **加密 DNS 与按规则解析** — DNS 请求走加密通道，按规则解析；
- **Fake-IP 模式** — 减少 DNS 泄露与解析等待；
- **关闭 IPv6** — 避免绕过代理的 IPv6 直连；
- **STUN 阻断**（规则模式）— 阻断 STUN 请求，降低真实 IP 暴露面。

## 检查当前状态

应用内的“安全防护”页可以检查当前运行中的 DNS 与 STUN 设置，并在应用内检测 WebRTC 候选。

检测结果反映当前应用和内核运行配置，不代表已验证所有浏览器、应用或网络路径。

::: tip 让 UDP 也走代理
STUN 与 WebRTC 相关的 UDP 流量需要 TUN 才能接管，见[接管与分流](/guide/routing)。
:::
