# Android 使用指南

PP Clash Android 端包含概览、节点、订阅、连接和更多页面。概览页显示当前节点、延迟和实时流量，连接按钮用于启动系统 VPN。

::: tip 已正式发布
Android 正式版已随 v0.2.3 发布。前往[下载页的 Android 分组](/download#download-android)获取 APK，或查看[本次更新](/guide/changelog)。
:::

## 系统与实测状态

| 设备 | 要求与状态 |
| --- | --- |
| ARM64 手机 | Android 7.0 及以上，选择 `arm64-v8a` APK；已在 Android 13 手机上验证 |
| x86_64 设备 | Android 7.0 及以上，选择 `x86_64` APK；安装包已发布，待实机验证 |

仅支持 64 位设备，多数 Android 手机选择 `arm64-v8a`。发布附件中的 `.aab` 用于应用分发，不能像 APK 一样直接安装。

## 安装与连接

1. 从[下载页](/download#download-android)下载与设备架构匹配的 APK，打开后按系统提示允许本次安装。若系统要求授权，请仅对用于打开 APK 的浏览器或文件管理器允许“安装未知应用”。
2. 进入底部“订阅”，导入自己的订阅链接或本地 Clash / mihomo 配置文件。
3. 进入“节点”，选择要使用的代理节点。
4. 回到“概览”，选择规则、全局或直连模式，点击连接按钮并允许系统 VPN 请求。
5. 确认状态显示“已连接”，查看当前节点、运行时间与上传、下载速率。

再次点击连接按钮可以断开 VPN。需要切换当前节点时，点击概览页的节点名称进入节点页。

v0.2.3 已内置分流数据库，首次导入不再需要额外下载这些数据库；界面会显示导入的当前阶段。导入订阅链接仍需要网络，具体配置引用的外部资源也可能需要下载。

::: danger 请自行准备订阅
PP Clash 不提供代理节点或订阅服务。连接前请导入自己的订阅或配置文件。
:::

## 常用操作

- **测速** — 点击概览页延迟圆环或测速按钮，查看当前节点的延迟。
- **订阅管理** — 更新、编辑、切换订阅，查看用量与到期信息；概览页也可更新当前订阅。
- **连接与流量** — 在“连接”查看活动连接，在“更多 → 流量统计”查看流量记录。
- **网络工具** — 在“更多”进入分流规则、DNS 配置和运行日志。
- **主题** — 在设置中选择浅色、深色或跟随系统。

Android 使用系统 VPN 服务接管流量。出站模式仍决定流量如何转发，详见[接管与分流](/guide/routing)。桌面端的内核版本管理、配置覆写、备份与恢复和 WebRTC 检测通过各自的桌面页面使用。

## 升级与迁移 {#upgrade}

设置页提供检查更新、启动时检查更新，以及下载后交由系统确认安装的入口。更新来源为 GitHub Releases，需要对应架构的 APK 和有效的 SHA-256 校验信息。

**正式版 → 后续正式版：**使用相同签名的对应架构 APK 覆盖安装，可保留订阅与设置。如果系统提示签名冲突，先确认原安装来源，不要直接卸载导致数据丢失。

手动校验时，从同一个 Release 下载 APK 和 `SHA256SUMS`，使用 SHA-256 工具计算 APK 摘要，并与清单中同名文件的值比较。校验方法见[下载与安装](/guide/install#verify-download)。
