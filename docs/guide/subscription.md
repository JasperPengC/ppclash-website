# 订阅与分组

PP Clash 的订阅与代理分组按实际配置呈现，不做写死或猜测。

## 导入订阅

订阅管理页支持两种来源：

- **订阅链接**：粘贴订阅 URL，按订阅的更新周期自动更新；
- **本地文件**：先选择并展示路径，再确认导入。

导入时数据层会校验配置结构与内核候选；非法或重复来源就地提示，失败保留草稿。Android 可从底部“订阅”添加，文件导入使用系统文件选择器。首次导入的订阅自动投入使用；已有订阅时，新增订阅不会抢占当前订阅。

Android v0.2.3 已内置分流数据库，首次导入无需额外下载这些数据库。导入时界面会显示当前阶段；订阅链接本身及配置引用的外部资源仍需能正常访问。

## 订阅信息

订阅卡显示：

- 名称与来源；
- 流量用量与剩余量（有配额时显示用量进度，未知配额不会画虚构进度）；
- 到期日期与剩余天数；
- 更新时间与更新操作。

桌面与 Android 使用统一的订阅卡片结构，更新、编辑与切换操作集中在卡片底部；删除订阅前会再次确认。

## 浏览分组与节点

- 分组名称、结构和顺序完全由订阅配置决定；
- 搜索节点、测试延迟、选择并固定常用节点；
- “选择”与“固定”分别显示：收藏或排序不会冒充实际固定；
- 节点名称完整显示、支持换行，延迟保持独立列。

再次打开应用时会恢复上次选择的节点。

## 快捷切换

桌面端托盘/菜单栏快捷面板（macOS 菜单栏 / Windows 托盘）可以查看当前状态，快速切换订阅、节点和出站模式；Windows 的速率显示在图标提示（tooltip）中。

Android 在订阅页可更新、编辑或切换订阅，概览页也提供更新当前订阅的按钮。
