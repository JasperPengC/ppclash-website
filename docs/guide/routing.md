# 接管与分流

## 出站模式

在窗口右上角（或快捷面板）可在三种模式间切换：

- **规则**：按订阅中的分流规则转发（推荐）；
- **全局**：所有流量经代理；
- **直连**：所有流量直接连接。

## 系统代理与 TUN

两种接管各自独立开关；TUN 开启时应用会阻止再开启系统代理，需先关闭 TUN。

| | 系统代理 | TUN |
| --- | --- | --- |
| 接管范围 | 系统代理流量 | 全部流量（按实际网卡与协议栈状态） |
| UDP | 不接管 | 接管 |
| 典型场景 | 日常浏览 | WebRTC 等需要 UDP 的应用 |

系统代理显示真实监听端口；TUN 显示实际网卡与协议栈状态，读取失败时显示“待确认”，不编造运行状态。

::: tip 需要 UDP 走代理？
系统代理不接管 UDP。需要路由 WebRTC 等协议使用的 UDP 流量时，请开启 TUN。
:::

## 稳定出口优先

- 测速不会切换节点；单站故障、403/429 不会触发换 IP；
- 后台保守故障切换沿用既定规则（两分钟、两站三轮、十分钟冷却）；
- 固定节点始终优先；确认连接状态请在概览页查看当前节点与延迟。

## 分流规则的边界

- 分组与规则来自你的订阅配置，应用不会按名称猜测业务含义后自动更改；
- 选择引用路径不等于物理转发链路，中间节点不等于最终出口；
- 来源或运行态不足时显示“未知”，不伪造全局当前节点。
