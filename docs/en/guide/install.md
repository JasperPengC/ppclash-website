Pick the installer that matches your operating system and CPU architecture. The list below is read automatically from the latest release on [GitHub Releases](https://github.com/JasperPengC/pp-clash/releases).

## macOS

Open the `.dmg` and drag PP Clash into your Applications folder.

::: warning Blocked on first launch?
The current test build is signed locally and not yet notarized by Apple. Find PP Clash under "System Settings → Privacy & Security" and click "Open Anyway".
:::

## Windows

Run the `-setup.exe` installer and follow the wizard.

## Linux

Install the `.deb` or `.rpm` package, or run the `.AppImage`.

Linux requires WebKitGTK 4.1 and Ayatana AppIndicator; the AppImage still uses the GTK and WebKitGTK libraries provided by the system.
