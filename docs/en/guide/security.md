# Security

## On by default

Configs generated by the app enable:

- **Encrypted DNS with rule-based resolution** — DNS requests travel encrypted and resolve by rule;
- **Fake-IP mode** — reduces DNS leaks and resolution waits;
- **IPv6 off** — avoids IPv6 direct connections that bypass the proxy;
- **STUN blocking** (rule mode) — blocks STUN requests to shrink your real-IP exposure.

## Check the running state

Results reflect the current app and core running configuration; they do not mean every browser, app or network path has been verified.
